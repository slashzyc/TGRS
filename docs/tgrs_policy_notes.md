## Format and review model

The [official TGRS author instructions](https://www.grss-ieee.org/publications/author-resources/tgrs-information-for-authors/) require PDF submissions, including revisions, in IEEE standard **double-column, single-spaced** format. Page numbers should run consecutively. The submission system adds line numbers, so manually adding them is unnecessary. References should use IEEE style. Figures and tables should be numbered, cited in the text, and placed near their discussion, with captions or titles that explain their content.

The [official TGRS peer-review page](https://www.grss-ieee.org/publications/author-resources/tgrs-peer-review/) describes **single-anonymous** review: reviewers know author identities. Adding the author list, affiliations, and corresponding-author information is therefore consistent with the journal's review model.

The [IEEE article-structure guidance](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/create-the-text-of-your-article/structure-your-article/) recommends a single-paragraph abstract of no more than 250 words. It should stand alone, and symbols or citations should be avoided. The final abstract must be checked against the completed manuscript rather than lengthened to satisfy a generic conference-writing prompt.

## Page length and 2026 charging threshold

For papers submitted after 1 January 2026, the TGRS author page states that mandatory overlength charges apply **beyond 10 printed pages, starting at page 11**. This is a charging threshold, **not a verified hard maximum manuscript length**. The current page charge and any membership or waiver rules should be checked again when the authors actually submit. No publication charge has been selected, incurred, or paid by this editing workflow.

The same page describes traditional and open-access routes. A publication route has not been selected on the authors' behalf.

## Availability and repository wording

The requested repository is [slashzyc/TGRS](https://github.com/slashzyc/TGRS). Availability statements must describe the files actually deposited there. Manuscript source, compiled files, revision notes, and extracted plot values are different deliverables from the original experiment code, predictor extracts, hashes, ledgers, and runtime environment.

Do not say that all research data and code are available or that an independent reproduction has passed merely because the edited manuscript is in GitHub. The original research-pack claims are preserved as source-study reports and bounded by the release's actual contents.

A statement that it has already been submitted should therefore not be added yet.
